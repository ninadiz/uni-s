- Регистрация организации в Яндекс Бизнесе → карточка в Яндекс Картах/Поиске.
- Нужны от заказчика: юр. название (ООО «Юни-С»), ИНН 7811631793, фактический адрес/офис, телефон, почта (`info@unis-tech.ru`), часы работы, категория деятельности, логотип, фото.

- Связать с Яндекс Метрикой (проверить, подключена ли Метрика — см. SEO-план).

### П3. 🟡 Оптимизация под AI-агентов (GEO / AEO — чтобы сайт читали и рекомендовали LLM)

Цель: когда человек спрашивает у ChatGPT / Алисы / Gemini / Perplexity что-то про алмазную резку, бурение, демонтаж в СПб и ЛО — модель ссылалась на сайт Uni-S и рекомендовала компанию.

**На стороне сайта (частично пересекается с пп. 5, 8 и SEO-планом):**

- **Доступ для ботов:** в `site/public/robots.txt` явно разрешить AI-краулеры (`GPTBot`, `OAI-SearchBot`, `ChatGPT-User`, `PerplexityBot`, `ClaudeBot`, `Claude-SearchBot`, `Google-Extended`, `YandexAdditional`). Решить с заказчиком осознанно — это разрешение обучаться/цитировать.
- **`llms.txt`:** добавить `site/public/llms.txt` (и опц. `llms-full.txt`) — краткий машиночитаемый обзор: чем занимается компания, услуги, регион, контакты, ссылки на ключевые страницы.
- **Контент, который LLM может процитировать дословно:**
  - Развёрнутый FAQ (см. п. 5) с прямыми вопросами-ответами («Чем алмазная резка отличается от отбойной?», «Можно ли резать несущую стену?», «Сколько стоит проём 900×2100?») — LLM любят Q&A-формат.
  - На страницах услуг — чёткие определения, для чего метод, ограничения, типы конструкций. Короткие абзацы, подзаголовки, списки.
  - Страница `/prices` с реальными цифрами (ждёт данные заказчика) — конкретные числа сильно повышают цитируемость.
- **Structured data (JSON-LD), в рантайме и пререндере:**
  - `Organization` / `LocalBusiness` — название, ИНН, адрес, гео, телефон, `areaServed` (СПб + ЛО), `sameAs` (VK, Яндекс Бизнес, Profi.ru).
  - `Service` для каждой услуги, `FAQPage` (п. 5), `BreadcrumbList`.
- **Семантика и скорость:** валидный HTML, осмысленные заголовки, `<main>`, alt у фото объектов, быстрый SSG-рендер (уже есть) — чтобы контент читался без исполнения JS.
- Sitemap с датами обновления, canonical (уже сделано в SEO-плане).

**Вне сайта (важнее для рекомендаций — LLM опираются на упоминания на сторонних ресурсах):**
