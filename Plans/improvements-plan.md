## Контент и продвижение (высокий приоритет)

### 1. 🟡 Оптимизация под AI-агентов (GEO / AEO) — приоритет №1

Цель: когда человек спрашивает у ChatGPT / Алисы / Gemini / Perplexity про алмазную резку, бурение, демонтаж в СПб и ЛО — модель ссылается на сайт Uni-S и рекомендует компанию.

- **Статус:** сайтовая часть сделана в ветке `feat/ai-optimizations` (не влита). Ждут заказчика: подтверждение по AI-ботам в `robots.txt`, ссылка на Profi.ru для `sameAs`.
- **Что сделано:**
  - Данные вынесены в модули-источники: [`src/content/company.ts`](../site/src/content/company.ts) (реквизиты, контакты, адрес, координаты, часы, регион, профили), [`services.ts`](../site/src/content/services.ts) (используется в `Services.tsx`), [`prices.ts`](../site/src/content/prices.ts) (используется в `Prices.tsx`). `Home.tsx` пока со своими короткими текстами — объединение в п. 2.
  - `robots.txt`: отдельная группа с явным `Allow` для `GPTBot`, `OAI-SearchBot`, `ChatGPT-User`, `PerplexityBot`, `Perplexity-User`, `ClaudeBot`, `Claude-SearchBot`, `Claude-User`, `Google-Extended`, `YandexAdditional`, `YandexAdditionalBot` (`/ui-kit` закрыт и для них).
  - `llms.txt` генерируется при пререндере ([`src/content/llms.ts`](../site/src/content/llms.ts)): описание, регион, контакты, услуги с описаниями, принципы ценообразования, все объекты со ссылками. `llms-full.txt` не делали — сайт маленький, полный текст и так влезает в `llms.txt`.
  - JSON-LD переехал из `index.html` в [`src/structuredData.ts`](../site/src/structuredData.ts) — один `@graph` на страницу, общий для пререндера и рантайма (`PageMeta.tsx` обновляет `<script id="structured-data">` при навигации). `LocalBusiness` получил `@id`, `alternateName`, `description`, `foundingDate`, `areaServed` как `AdministrativeArea`, адрес (Складская ул., 6Б), `geo`, `openingHoursSpecification` (пн–пт 08:00–20:00), `hasMap` и `sameAs` (VK, [Яндекс Карты](https://yandex.ru/maps/org/yuni_s/163347240278/)). Адрес, координаты и часы взяты из карточки на Яндекс Картах.
  - `BreadcrumbList` на всех индексируемых внутренних страницах и `/objects/:slug`; на `/services` — `ItemList` из `Service` с `provider` → организация.
  - В `pageMeta.ts` добавлено поле `name` (короткое имя страницы для хлебных крошек и `llms.txt`).
  - Sitemap: `<lastmod>` = дата последнего git-коммита, затронувшего источники страницы (`sources` в `scripts/routes.mjs`, для объектов — их папка); без git тег не пишется.
  - Мелочи по контенту объектов (LLM цитируют дословно): опечатки в `info.json` («вентилляция», «реконструции», «бассеина», «помещение»), латинская «K» в «ЖК Новоселье»; meta description для объектов без описания больше не начинается с «. Проект…».
- **Проверено:** `npm run build` + `npm run lint`; в пререндере на каждой странице один `h1`, есть `<main>`, у всех `<img>` есть `alt`; в dev при навигации JSON-LD меняется, тег один, ошибок в консоли нет. Осталось прогнать валидаторы Google Rich Results / Яндекса после деплоя.

- Sitemap с `lastmod` (проверить, что даты реальные, а не дата сборки).

**Вне сайта (LLM опираются на упоминания на сторонних ресурсах):**

### 4. 🟡❓ Аналитика: Яндекс Метрика + Google Analytics, плашка согласия на cookie

- **Вводные от заказчика:** ID счётчика Метрики и GA4 (или доступ, чтобы создать на их аккаунт); цели для конверсий (клик по телефону, почте, VK).
- **Плашка cookie:**
  - Компонент `CookieConsent.tsx`: короткий текст + ссылка на `/privacy`, кнопки «Принять» / «Только необходимые». Выбор хранить в `localStorage`.
  - **Счётчики грузятся только после согласия** (152-ФЗ: cookie аналитики — персональные данные). До согласия — ни одного внешнего запроса.
  - Не перекрывать плавающую кнопку звонка на мобилке (`FloatingCall`, `z-40`) — плашка выше неё или кнопка сдвигается, пока плашка видна.
  - Обновить текст `/privacy` и `/consent`: какие cookie, какие сервисы, цели. ❓ Финальный текст утверждает заказчик.
- **Счётчики:**
  - Метрика: Вебвизор, карта кликов, цели `tel:` / `mailto:` / VK. Отправка хитов при SPA-переходах (`react-router` → `ym(id, 'hit', url)`).
  - GA4 через `gtag.js`, `page_view` на смене роута.
  - Подключать только в проде (не на `localhost` и не в пререндере).
  - ❓ **Риск GA:** данные уходят на серверы в США — это трансграничная передача ПДн, по 152-ФЗ требует уведомления Роскомнадзора. Решить с заказчиком: оставляем GA (и подаём уведомление) или ограничиваемся Метрикой.
- **Связки:** Метрика ↔ Яндекс Вебмастер ↔ Яндекс Бизнес; Google Search Console.
- **Исключение из общих требований:** «без внешних запросов» — не касается счётчиков после согласия.

## Общие требования ко всем PR

- Сборка проходит: `cd site && npm run build` (tsc + vite build + SSR + prerender + sitemap).
- Lint: `npm run lint` (oxlint).
- Пререндер не сломан — проверить HTML в `dist/`.
- Нет горизонтального скролла на мобилке, десктоп не задет там, где правки только мобильные.
- `prefers-reduced-motion` учтён для новых анимаций.
- Без внешних запросов (шрифты/скрипты self-hosted). Исключение — счётчики аналитики после согласия на cookie (п. 4).
