Как добавлять новые объекты в эту папку
========================================

Каждый реализованный объект (кейс для секции «Объекты» на сайте) — это
отдельная подпапка внутри src/assets/objects/. Подпапка содержит:

  1. Фотографии объекта (любое количество).
  2. Файл info.json с описанием объекта.

Название папки
---------------
Формат: (что за объект)-(локация), c транслитерацией в латиницу.

Примеры:
  zhiloy-kompleks-novoselye
  biznes-tsentr-ligovsky
  skladskoy-kompleks-zausadebnaya

Все с маленькой буквы и через "-" .

Формат фотографий
------------------
Кладите фото в веб-форматах (jpg, png, webp). Файлы .HEIC (стандартный
формат iPhone) браузер показать не может — их нужно предварительно
сконвертировать в jpg или webp, прежде чем добавлять в папку.
Claude может конвертировать .HEIC через sips — встроенную утилиту macOS.

info.json
---------
Внутри каждой папки лежит info.json со следующими полями (все — строки,
кроме year):

{
  "header": "",
  "objectName": "",
  "clientName": "",
  "description": "",
  "year": 2025
}

  header      — короткий заголовок для карточки объекта на сайте.
  objectName  — полное название объекта (например, "Порт в Усть-Луге").
  clientName  — название клиента/заказчика.
  description — что именно было сделано на объекте.
  year        — год выполнения работ (число, не строка).

Пустая строка "" означает "данные ещё не заполнены".
